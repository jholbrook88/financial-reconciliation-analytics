# Data

The `charles_river` folder contains the source tables used by the program. Its
`GLEntry.csv` file is limited to the cash-account rows needed for this project.

The `sample` folder contains a simulated bank statement with four added test
transactions:

- monthly account-maintenance fee
- returned customer ACH
- wire-processing fee
- monthly interest credit

The data is fictional. Source and license information is in `DATA_LICENSE.md`.
