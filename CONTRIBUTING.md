# Contributing

This is a portfolio and learning project, but reproducible improvements are
welcome.

1. Create a feature branch.
2. Keep matching rules explicit and one-to-one.
3. Add or update unit tests for behavioral changes.
4. Run `python -m unittest discover -s tests -v` before opening a pull request.
5. Do not commit confidential or real customer financial data.

Generated reconciliation outputs are intentionally ignored. Summarize durable
results in `reports/RESULTS.md` instead.
